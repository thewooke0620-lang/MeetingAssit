# 회의 통역 도우미 (MeetingAssit)

영어 회의 소리를 실시간으로 받아 영어 자막과 한국어 번역을 보여 주는 웹 앱입니다.

- 실행: https://thewooke0620-lang.github.io/MeetingAssit/
- 음성 인식·번역: Soniox 실시간 API (사용자가 자신의 API 키를 설정 화면에 입력)
- 설치 없음. 크롬 또는 엣지에서 주소를 열어 사용합니다.

## 사용 방법
1. 설정에서 Soniox API 키를 입력합니다. 키는 해당 브라우저에만 저장됩니다.
2. 시작을 누르고, 화면 공유 창에서 "전체 화면"과 "시스템 오디오도 공유"를 선택합니다.
3. 폰에서는 마이크 입력으로 동작합니다.

## 구성
- `index.html`: 앱 전체 (파일 하나)
- `docs/requirements.md`: 요구사항 정의서
