# 회의 통역 도우미 (MeetingAssit)

영어 회의 소리를 실시간으로 받아 영어 자막과 한국어 번역을 보여 주는 웹 앱입니다.

- 실행: https://thewooke0620-lang.github.io/MeetingAssit/
- 음성 인식·번역: Soniox 실시간 API (사용자가 자신의 API 키를 설정 화면에 입력)
- AI 번역(선택): Claude 또는 Groq. 각자 자신의 API 키를 설정 화면에 입력
- 설치 없음. 크롬 또는 엣지에서 주소를 열어 사용합니다.

## 사용 방법
1. 설정에서 Soniox API 키를 입력합니다. 키는 해당 브라우저에만 저장됩니다.
2. 시작을 누르고, 화면 공유 창에서 "전체 화면"과 "시스템 오디오도 공유"를 선택합니다.
3. 폰에서는 마이크 입력으로 동작합니다.

## 회의 묶음과 회의 기록
- **회의 묶음**: 회의 종류나 상대별로 묶음을 만들면 회의 배경, 용어집, 지난 회의 기록이 묶음마다 따로 보관됩니다. 화면 위의 "묶음: ○○"를 눌러 바꿉니다.
- **자동 저장**: 회의 중 30초마다, 그리고 정지할 때 영어 원문과 번역이 고른 묶음에 저장됩니다. 소리는 저장하지 않습니다. 설정에서 끌 수 있습니다.
- **백업**: 묶음과 기록은 그 브라우저에만 저장됩니다. "전체 내보내기"로 파일에 보관하고 "가져오기"로 되살립니다. API 키는 백업에 들어가지 않습니다.

## 번역 품질과 속도 설정 (번역 방식이 Claude 또는 Groq일 때)
- **Groq**: 응답이 빠른 번역 엔진입니다. 번역 방식을 Groq으로 두면 전부 Groq이 번역하고, Claude로 두고 Groq 키만 넣으면 말하는 도중의 미리 번역만 Groq이 맡습니다.
- **회의 배경**: 회의 주제, 참석자, 쟁점을 적어 두면 상황에 맞게 번역합니다.
- **용어집**: 한 줄에 하나씩 적습니다. `escrow = 에스크로`처럼 적으면 항상 그 표현으로 번역하고, 영어만 적으면 그대로 둡니다.
- **긴 문장 다듬기**: 긴 문장을 쉼표에서 끊어 먼저 번역하고, 문장이 끝나면 전체를 다시 번역해 한 줄로 고칩니다.
- **번역 비교 모드**: Soniox 번역과 다른 AI 엔진의 번역을 작은 글씨로 함께 보여 줍니다. 이름 옆 숫자는 문장이 끝난 뒤 그 엔진의 번역이 완성될 때까지 걸린 시간입니다. 품질과 속도를 비교할 때만 켭니다.
- **번역 속도 기록**: 화면 위쪽의 "미리 ○초 · 확정 ○초"를 누르면 Soniox, Claude, Groq의 속도를 같은 기준으로 잰 값(평균, 보통, 느릴 때)을 볼 수 있습니다.
