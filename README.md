# 회의 통역 도우미 (MeetingAssit)

영어 회의 소리를 실시간으로 받아 영어 자막과 한국어 번역을 보여 주는 웹 앱입니다.

- 실행: https://thewooke0620-lang.github.io/MeetingAssit/
- 음성 인식·번역: Soniox 실시간 API (사용자가 자신의 API 키를 설정 화면에 입력)
- AI 번역(선택): Claude 또는 Groq. 각자 자신의 API 키를 설정 화면에 입력
- 설치 없음. 크롬 또는 엣지에서 주소를 열어 사용합니다.

## 사용 방법
0. 처음 열면 **사용자 등록** 창이 뜹니다: 내 이름 → API 키(연결 시험) → 계정(Supabase) → 내 목소리(영어 글 읽기, 약 10초) → 첫 회의 묶음(이름·주제·참여자). 나중에 설정 맨 위 '나'에서 다시 할 수 있습니다.
1. 설정에서 Soniox API 키를 입력합니다. 키는 해당 브라우저에만 저장됩니다.
2. 시작을 누르고, 화면 공유 창에서 "전체 화면"과 "시스템 오디오도 공유"를 선택합니다.
3. 폰에서는 마이크 입력으로 동작합니다.

## 계정 화면과 내 지식 (개인화)
- 오른쪽 위 계정 단추: 개인화 수준(레벨 1~6)과 '개인화 관리하기', 내 목소리 등록, **회의 기록에서 다시 듣기**, **앱을 나가도 계속 기록하기**.
- 계정 화면의 **회의 후 자동으로 배우기**: 회의 정리가 끝나면 용어·하는 일·말투를 고칩니다.
- **내 지식** (개인화 관리하기): 지난 회의에서 배우기, 고유 용어(모든 묶음에 쓰임), 다른 AI에서 가져오기(보낼 글을 복사 → 받은 답을 붙여 넣기), 저장된 지식(기본 정보·지금 하는 일·내 관점·말투) 보기·고치기·초기화. 고유 용어는 받아 적기와 번역 용어집에, 하는 일·말투는 답변 제안에 쓰입니다. 이 기기와 내 계정에 저장하고, 번역·제안을 만들 때 고른 AI에 함께 보냅니다.
- **다시 듣기**: 회의 소리를 이 기기(IndexedDB)에만 저장합니다 (1시간에 약 11MB). 회의 기록의 플레이어나 줄마다 '▶ 듣기'로 그 줄부터 듣습니다. 서버에는 올리지 않아 녹음한 기기에서만 들을 수 있습니다.
- **앱을 나가도 계속 기록하기**: 안드로이드 앱은 '회의 기록 중' 알림(포그라운드 서비스)을 띄워 다른 앱을 보거나 화면을 잠가도 계속 듣습니다. 끄면 앱을 떠날 때 회의가 멈춥니다.

## 가입 확인 메일 (Supabase 설정)
- Supabase 대시보드 → Authentication → URL Configuration 에서 **Site URL** 을 `https://thewooke0620-lang.github.io/MeetingAssit/` 로, **Redirect URLs** 에 같은 주소를 넣어야 확인 메일의 링크가 이 앱으로 돌아옵니다 (기본값 localhost 이면 링크가 localhost 로 가서 열리지 않습니다).
- 링크로 돌아오면 앱이 그대로 로그인합니다. 링크가 만료됐으면 '확인 메일 다시 보내기'를 누릅니다.

## 내 말과 상대 말 구분
- 등록한 내 목소리(6초 정도)를 Soniox 연결 맨 앞에 먼저 보내, 화자 구분이 그 목소리에 붙인 화자를 '나'로 표시합니다 (초록 띠, "이름 (나)"). 그 구간의 글자와 번역은 화면에 나오지 않습니다.
- PC에서는 들을 소리를 **PC 소리 + 내 마이크**로 고르면 내 말도 받아 적고, 마이크 쪽 소리가 큰 말을 '나'로 더 정확히 가립니다. 헤드셋을 쓰면 가장 정확합니다.
- 틀리게 표시되면 화자 이름을 눌러 '나'라고 적거나, '나' 줄에 다른 이름을 적어 고칩니다.
- 내가 한 질문에는 답변 제안을 하지 않고, 회의 정리에서도 내 말을 구분합니다.
- 이름·목소리는 로그인한 계정으로 PC·폰이 함께 씁니다. 실제 회의 소리로 얼마나 정확한지는 직접 써 보며 확인해야 합니다.

## 회의 묶음과 회의 기록
- **묶음 만들기**: 이름과 함께 주제, 자주 만나는 참여자, 배경을 적습니다. **회의 시작 전**에는 이번 회의 주제와 참여자를 적습니다 (묶음의 참여자는 눌러서 고름). 새 참여자는 묶음에 쌓입니다.
- **번역에 쓰는 묶음 자료**: 묶음 주제·참여자·배경·쌓인 내용과 이번 회의 주제·참여자, 내 이름을 Soniox(받아 적기 용어와 회의 배경)와 Claude·Groq 번역 지시에 함께 넘깁니다. 회의가 쌓일수록 용어집과 쌓인 내용이 늘어 다음 회의 번역에 쓰입니다.
- **회의 묶음**: 회의 종류나 상대별로 묶음을 만들면 회의 배경, 용어집, 지난 회의 기록이 묶음마다 따로 보관됩니다. 화면 위의 "묶음: ○○"를 눌러 바꿉니다.
- **자동 저장**: 회의 중 30초마다, 그리고 정지할 때 영어 원문과 번역이 고른 묶음에 저장됩니다. 소리는 저장하지 않습니다. 설정에서 끌 수 있습니다.
- **회의 제목**: 정지하면 회의 내용을 보고 제목을 자동으로 붙입니다. 지난 회의 목록에 날짜와 제목이 함께 나오고, "제목 수정"으로 고칠 수 있습니다. 내려받은 파일 맨 위에도 제목, 일시, 묶음이 적힙니다.
- **백업**: 묶음과 기록은 그 브라우저에만 저장됩니다. "전체 내보내기"로 파일에 보관하고 "가져오기"로 되살립니다. API 키는 백업에 들어가지 않습니다.

## 안드로이드 앱 (APK)
- 폰에서 https://github.com/thewooke0620-lang/MeetingAssit/raw/apk/MeetingAssit.apk 를 열어 받고 설치합니다. "출처를 알 수 없는 앱" 설치를 허용해야 할 수 있습니다.
- 처음 회의를 시작할 때 마이크 권한을 허용합니다. 앱이 켜져 있는 동안 화면이 꺼지지 않습니다.
- 앱 화면은 웹 앱 주소를 불러오므로 웹을 고치면 다시 깔지 않아도 반영됩니다. APK 는 `android/` 를 고치면 GitHub 서버(Actions)가 다시 만듭니다.

## 폰 앱 (설치형 웹 앱)
- **안드로이드(크롬)**: 앱 주소를 열면 시작 화면이나 왼쪽 메뉴에 **앱으로 설치**가 나옵니다. 누르면 홈 화면에 '회의통역' 아이콘이 생깁니다. (안 보이면 크롬 메뉴 ⋮ → 앱 설치 / 홈 화면에 추가)
- **아이폰(사파리)**: 아래쪽 공유 단추(□↑) → **홈 화면에 추가**.
- 설치하면 주소창 없이 전체 화면으로 열리고, 웹 앱을 고치면 다음에 열 때 자동으로 새 버전이 됩니다.
- 폰에서는 다른 앱(Teams 등)의 소리를 직접 받을 수 없어 **마이크**로 듣습니다. 화면이 꺼지거나 다른 앱으로 넘어가면 듣기가 멈출 수 있습니다.
- 같은 계정으로 로그인하면 PC(exe·브라우저)의 회의 기록이 폰에서도 보입니다.

## 데스크톱 앱 (Windows exe)
- `MeetingAssit-Setup-…exe`(설치형) 또는 `MeetingAssit-…-portable.exe`(설치 없이 바로 실행) 중 하나를 실행합니다. 파일은 `desktop/` 에서 빌드합니다 (만드는 법은 CLAUDE.md).
- 서명하지 않은 프로그램이라 처음 실행할 때 "Windows의 PC 보호" 창이 뜰 수 있습니다. **추가 정보 → 실행**을 누르면 됩니다.
- 웹 앱과 다른 점
  - **컴퓨터 소리 바로 듣기**: "들을 소리"를 "컴퓨터 소리"로 두면 공유 창 없이 Zoom·Teams 등의 소리를 바로 듣습니다. (컴퓨터에서 나는 모든 소리를 듣습니다)
  - **자막 팝업(작은 창)**: 누르면 본 창과 따로, 화면 아래쪽에 반투명 자막 팝업이 떠서 Teams 등 다른 창 위에 늘 있습니다. 마지막 두 줄만 크게 보이고, 뒤가 흐리게 비칩니다(Windows 11. Windows 10에서는 흐림 없이 어두운 바탕). 팝업 위쪽에서 흐림 켜기·끄기, 투명도, ★ 중요 표시, 본 화면, 정지, ✕(닫기)를 쓸 수 있고, 위쪽 막대를 끌어 옮기고 가장자리를 끌어 크기를 바꿉니다.
- 화면은 웹 앱 주소를 불러와 쓰므로, 웹 앱을 고치면 exe를 다시 깔지 않아도 다음 실행(또는 F5)부터 반영됩니다. 인터넷이 없으면 안내 화면이 나옵니다.
- 회의 기록과 키는 웹 앱(브라우저)과 따로 저장됩니다. 브라우저에서 쓰던 기록은 설정의 "내보내기"로 백업한 뒤 exe에서 "가져오기"로 옮깁니다.

## 계정과 동기화 (Supabase)
- 설정 맨 위 "계정과 동기화"에서 이메일·비밀번호로 가입하거나 로그인합니다. (Supabase 주소와 공개 키는 앱에 들어 있습니다)
- 로그인하면 회의 묶음과 기록을 Supabase에도 저장하고, 같은 계정으로 로그인한 다른 기기(exe, 브라우저, 폰)와 자동으로 맞춥니다. API 키는 올리지 않습니다.
- 기록은 먼저 이 기기에 저장되므로 인터넷이 끊겨도 회의는 그대로 됩니다. 올리지 못한 것은 기억해 두었다가 연결되면 올립니다. 회의 중에는 1분에 한 번, 끝나면 바로 올립니다.
- 다른 기기에서 바뀐 것은 5분마다, 앱 창으로 돌아올 때, "지금 동기화"를 누를 때 받습니다. 두 기기에서 같은 회의를 고치면 나중에 올린 쪽이 남습니다.
- 처음 로그인하면 이 기기에 있던 기록도 올립니다. 같은 PC에서 다른 계정으로 로그인하면 이전 계정의 기록은 새 계정에 올리지 않습니다.
- 왼쪽 메뉴 아래 ☁ 줄에서 동기화 상태를 볼 수 있습니다.
- Supabase 프로젝트 `MeetingAssit`(서울)에 표와 보안 규칙이 만들어져 있습니다 (`docs/supabase.sql`).

## 연결이 끊겼을 때와 저장 상태
- **자동 재연결**: 인터넷이 잠깐 끊겨도 회의를 멈추지 않고 계속 다시 연결합니다 (0.5초, 1초, 2초… 최대 10초 간격). 키가 틀렸거나 잔액이 없을 때만 멈춥니다. 그만두려면 정지를 누릅니다.
- **끊긴 구간 표시**: 끊긴 동안의 소리는 30초까지 모아 두었다가 다시 연결되면 보냅니다. 연결이 이어지면 기록 사이에 노란 ⚠ 줄로 몇 초 끊겼는지, 빠진 소리가 있는지 표시하고, 저장한 기록과 내려받은 파일에도 남습니다.
- **정지 후 저장**: 정지하면 마지막 글자와 마지막 번역이 끝나기를 기다렸다가(최대 15초) 저장합니다. 그 안에 번역이 안 오면 영어 원문을 먼저 저장하고 "마지막 ○줄은 번역 전 저장"이라고 알려 줍니다.
- **저장 표시**: 위쪽에 "저장됨 ○시 ○분"이 보입니다. 저장에 실패하면 빨간 "저장 실패"로 바뀌고, 누르면 지금까지의 기록을 파일로 받습니다.
- **연결 시험**: 설정의 "연결 시험"을 누르면 입력한 키로 Soniox, Claude, Groq에 짧게 접속해 쓸 수 있는지, 안 되면 무엇이 문제인지(키, 잔액, 모델, 인터넷) 알려 줍니다.
- **회의 정리 시간 제한**: 정리 요청이 90초 안에 끝나지 않으면 그만두고, AI 서비스가 혼잡하면 한 번 더 시도합니다. 실패해도 회의 기록은 그대로 남습니다.

## 화면 구성
- **탭 4개**: 홈(처음 시작하기 체크리스트, 새 회의, 최근 회의) · 준비(회의 묶음마다 배경·용어집·질문 준비) · 리포트(지난 회의를 달별로, 제목·내용으로 찾기) · 표현(용어집, 자주 받는 질문과 내 답변, 중요 표시한 발언). 폰에서는 아래쪽 탭 막대와 오른쪽 아래 **회의 시작** 단추로, PC에서는 왼쪽 메뉴로 엽니다.
- **계정 단추**(오른쪽 위): 로그인 상태, 이번 달 회의 시간, 기기끼리 맞추기, 앱 받기, 설정·백업·사용법.
- **왼쪽 메뉴**: "새 회의", 회의 묶음 ▸ 그 묶음의 회의 목록(나무 모양), "새 묶음", "설정". 묶음 이름을 누르면 그 묶음으로 회의하고, ▶를 누르면 펼치거나 접습니다. 회의를 누르면 정리 화면이 열립니다. 왼쪽 위 ☰로 메뉴를 접고 펼 수 있고, 폰에서는 ☰를 누르면 왼쪽에서 밀려 나옵니다.

## 회의 중 눈에 띄게 보기
- **내 이름 강조**: 설정의 "회의에서 나를 부르는 이름"에 `David, Dave`처럼 적으면, 그 이름이 나온 줄은 파란 바탕으로 표시됩니다. 나에게 묻거나 부탁한 말이면 물음표가 없어도 답변을 제안합니다.
- **질문 알아채기**: "Could you…", "Let me know…", "What do you think…"처럼 물음표가 없는 부탁도 알아챕니다. "John, can you…"처럼 다른 사람 이름을 부르며 한 질문은 자동 제안하지 않습니다 ("지금 제안"으로는 가능).
- **숫자·날짜·부정 표현 강조**: 금액, 퍼센트, 기간, 요일은 하늘색, not·can't·never 같은 부정 표현은 붉은 밑줄로 표시됩니다. 설정에서 끌 수 있습니다.
- **중요 표시**: 줄 오른쪽의 ☆를 누르거나 키보드 **B**를 누르면 방금 끝난 줄에 ★이 붙습니다. 회의 정리 화면 맨 위와 내려받은 파일에 모아서 보여 줍니다.
- **원문 이동**: 회의 정리의 결정 사항·할 일 옆 "원문 ○○:○○" 단추를 누르면 그 말이 나온 줄로 옮겨 가서 표시합니다. 어느 줄인지는 AI가 짚은 것이라 가끔 틀릴 수 있습니다.

## 빠른 답변, 자막 고치기, 지난 회의와 비교
- **빠른 답변 단추**: 답변 제안 칸 아래의 "다시 설명 요청", "내 이해 확인", "확인 후 회신", "일정 조율", "잠시 생각", "동의", "정중한 반대"를 누르면, 방금 오간 대화에 맞춘 영어 문장 2개를 만들어 줍니다. 날짜처럼 정해지지 않은 부분은 [date]처럼 비워 둡니다.
- **자막 고치기**: 줄에 마우스를 올리면 ★ 아래에 ✎가 보입니다. 누르고 영어를 고치면 (AI 번역 방식일 때) 고친 문장으로 다시 번역합니다. 바뀐 낱말이 있으면 "용어집에 넣을까요?"라고 묻고, 넣으면 번역에는 바로, 음성 인식에는 다음 시작부터 반영됩니다. 저장된 회의도 회의 정리 화면의 전체 기록에서 ✎로 영어와 한국어를 고칠 수 있습니다.
- **지난 회의 대비 변경점**: 같은 묶음에 정리가 있는 앞 회의가 있으면, 회의 정리에 "지난 회의 대비 변경점"이 생깁니다 (예: "납기: 6주 → 8주"). 아래에 비교한 회의 이름이 나오고, "원문" 단추로 그 말이 나온 줄로 갈 수 있습니다.

## 기타 설정
- **답변 제안·회의 정리에 쓸 AI**: 번역 엔진과 따로 고를 수 있습니다. 예) 번역은 Groq, 회의 정리는 Claude Sonnet.
- **키 기억하기**: 끄면 API 키를 브라우저 창을 닫을 때 지웁니다. "키 모두 지우기"로 바로 지울 수도 있습니다.
- **버전**: 설정 창 왼쪽 아래에 버전이 보입니다. 새 버전이 올라오면 회의 중이 아닐 때 새로고침하라고 알려 줍니다.
- **정리 갱신**: 줄 수가 같아도 기록 내용이 바뀌면 정리를 새로 만듭니다.
- **되살리기**: 첫 화면의 "백업 파일에서 되살리기"로 백업 파일을 바로 고를 수 있습니다.

## 회의 정리와 답변 제안 (Claude 또는 Groq 키가 있을 때)
- **회의 정리**: 정지하면 회의 내용을 보고 제목, 요약, 결정 사항, 할 일을 만듭니다. 위쪽 "회의 정리" 버튼이나 지난 회의의 "열기"로 봅니다. 회의 중에 눌러도 그때까지의 내용을 정리합니다.
- **묶음에 쌓기**: 정리에서 뽑힌 새 용어, 기억해 둘 내용, 받은 질문 가운데 맞는 것만 골라 묶음에 추가합니다. 추가한 내용은 설정의 회의 묶음에서 고칠 수 있고, 다음 회의의 번역과 답변 제안에 쓰입니다.
- **답변 제안**: 물음표로 끝나는 말이 들리면 영어로 할 수 있는 답변 두 가지를 화면 아래에 제안합니다. 제안을 누르면 영어 문장이 복사됩니다. "지금 제안"은 질문이 아니어도 방금 들린 말에 대해 제안합니다.
- **한국어를 영어로**: 답변 제안 칸 아래에 한국어로 적고 Enter를 누르면 회의에서 쓸 영어 표현으로 바꿔 줍니다.
- **내 정보, 쌓인 내용, 자주 받는 질문과 내 답변**: 설정에 적어 두면 답변 제안이 이 내용을 바탕으로 만들어집니다.
- **백업 알림**: 백업한 뒤 회의가 5건 쌓이면 하루에 한 번 알려 줍니다.

## 번역 품질과 속도 설정 (번역 방식이 Claude 또는 Groq일 때)
- **Groq**: 응답이 빠른 번역 엔진입니다. 번역 방식을 Groq으로 두면 전부 Groq이 번역하고, Claude로 두고 Groq 키만 넣으면 말하는 도중의 미리 번역만 Groq이 맡습니다.
- **회의 배경**: 회의 주제, 참석자, 쟁점을 적어 두면 상황에 맞게 번역합니다.
- **용어집**: 한 줄에 하나씩 적습니다. `escrow = 에스크로`처럼 적으면 항상 그 표현으로 번역하고, 영어만 적으면 그대로 둡니다.
- **안정 모드**: 한 줄의 번역이 Soniox 번역에서 확정 번역으로 한 번만 바뀝니다. 미리 번역과 긴 문장 다듬기를 쓰지 않습니다.
- **긴 문장 다듬기**: 긴 문장을 쉼표에서 끊어 먼저 번역하고, 문장이 끝나면 전체를 다시 번역해 한 줄로 고칩니다.
- **번역 비교 모드**: Soniox 번역과 다른 AI 엔진의 번역을 작은 글씨로 함께 보여 줍니다. 이름 옆 숫자는 문장이 끝난 뒤 그 엔진의 번역이 완성될 때까지 걸린 시간입니다. 품질과 속도를 비교할 때만 켭니다.
- **번역 속도 기록**: 화면 위쪽의 "미리 ○초 · 확정 ○초"를 누르면 Soniox, Claude, Groq의 속도를 같은 기준으로 잰 값(평균, 보통, 느릴 때)을 볼 수 있습니다.
