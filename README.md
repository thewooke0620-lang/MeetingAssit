# 회의 통역 도우미 (MeetingAssit)

영어 회의 소리를 실시간으로 받아 영어 자막과 한국어 번역을 보여 주는 웹 앱입니다.

- 실행: https://thewooke0620-lang.github.io/MeetingAssit/
- 음성 인식·번역: Soniox 실시간 API (사용자가 자신의 API 키를 설정 화면에 입력)
- AI 번역(선택): Claude 또는 Groq. 각자 자신의 API 키를 설정 화면에 입력
- 설치 없음. 크롬 또는 엣지에서 주소를 열어 사용합니다.

## 사용 방법
1. 설정에서 Soniox API 키를 입력합니다. 키는 해당 브라우저에만 저장됩니다.
2. 시작을 누르고, 화면 공유 창에서 "전체 화면"과 "시스템 오디오도 공유"를 선택합니다.
3. 폰에서는 마이크 입력으로 동작합니다.

## 회의 묶음과 회의 기록
- **회의 묶음**: 회의 종류나 상대별로 묶음을 만들면 회의 배경, 용어집, 지난 회의 기록이 묶음마다 따로 보관됩니다. 화면 위의 "묶음: ○○"를 눌러 바꿉니다.
- **자동 저장**: 회의 중 30초마다, 그리고 정지할 때 영어 원문과 번역이 고른 묶음에 저장됩니다. 소리는 저장하지 않습니다. 설정에서 끌 수 있습니다.
- **회의 제목**: 정지하면 회의 내용을 보고 제목을 자동으로 붙입니다. 지난 회의 목록에 날짜와 제목이 함께 나오고, "제목 수정"으로 고칠 수 있습니다. 내려받은 파일 맨 위에도 제목, 일시, 묶음이 적힙니다.
- **백업**: 묶음과 기록은 그 브라우저에만 저장됩니다. "전체 내보내기"로 파일에 보관하고 "가져오기"로 되살립니다. API 키는 백업에 들어가지 않습니다.

## 연결이 끊겼을 때와 저장 상태
- **자동 재연결**: 인터넷이 잠깐 끊겨도 회의를 멈추지 않고 계속 다시 연결합니다 (0.5초, 1초, 2초… 최대 10초 간격). 키가 틀렸거나 잔액이 없을 때만 멈춥니다. 그만두려면 정지를 누릅니다.
- **끊긴 구간 표시**: 끊긴 동안의 소리는 30초까지 모아 두었다가 다시 연결되면 보냅니다. 연결이 이어지면 기록 사이에 노란 ⚠ 줄로 몇 초 끊겼는지, 빠진 소리가 있는지 표시하고, 저장한 기록과 내려받은 파일에도 남습니다.
- **정지 후 저장**: 정지하면 마지막 글자와 마지막 번역이 끝나기를 기다렸다가(최대 15초) 저장합니다. 그 안에 번역이 안 오면 영어 원문을 먼저 저장하고 "마지막 ○줄은 번역 전 저장"이라고 알려 줍니다.
- **저장 표시**: 위쪽에 "저장됨 ○시 ○분"이 보입니다. 저장에 실패하면 빨간 "저장 실패"로 바뀌고, 누르면 지금까지의 기록을 파일로 받습니다.
- **연결 시험**: 설정의 "연결 시험"을 누르면 입력한 키로 Soniox, Claude, Groq에 짧게 접속해 쓸 수 있는지, 안 되면 무엇이 문제인지(키, 잔액, 모델, 인터넷) 알려 줍니다.
- **회의 정리 시간 제한**: 정리 요청이 90초 안에 끝나지 않으면 그만두고, AI 서비스가 혼잡하면 한 번 더 시도합니다. 실패해도 회의 기록은 그대로 남습니다.

## 회의 중 눈에 띄게 보기
- **내 이름 강조**: 설정의 "회의에서 나를 부르는 이름"에 `David, Dave`처럼 적으면, 그 이름이 나온 줄은 파란 바탕으로 표시됩니다. 나에게 묻거나 부탁한 말이면 물음표가 없어도 답변을 제안합니다.
- **질문 알아채기**: "Could you…", "Let me know…", "What do you think…"처럼 물음표가 없는 부탁도 알아챕니다. "John, can you…"처럼 다른 사람 이름을 부르며 한 질문은 자동 제안하지 않습니다 ("지금 제안"으로는 가능).
- **숫자·날짜·부정 표현 강조**: 금액, 퍼센트, 기간, 요일은 하늘색, not·can't·never 같은 부정 표현은 붉은 밑줄로 표시됩니다. 설정에서 끌 수 있습니다.
- **중요 표시**: 줄 오른쪽의 ☆를 누르거나 키보드 **B**를 누르면 방금 끝난 줄에 ★이 붙습니다. 회의 정리 화면 맨 위와 내려받은 파일에 모아서 보여 줍니다.
- **원문 이동**: 회의 정리의 결정 사항·할 일 옆 "원문 ○○:○○" 단추를 누르면 그 말이 나온 줄로 옮겨 가서 표시합니다. 어느 줄인지는 AI가 짚은 것이라 가끔 틀릴 수 있습니다.

## 빠른 답변, 자막 고치기, 지난 회의와 비교
- **빠른 답변 단추**: 답변 제안 칸 아래의 "다시 설명 요청", "내 이해 확인", "확인 후 회신", "일정 조율", "잠시 생각", "동의", "정중한 반대"를 누르면, 방금 오간 대화에 맞춘 영어 문장 2개를 만들어 줍니다. 날짜처럼 정해지지 않은 부분은 [date]처럼 비워 둡니다.
- **자막 고치기**: 줄에 마우스를 올리면 ★ 아래에 ✎가 보입니다. 누르고 영어를 고치면 (AI 번역 방식일 때) 고친 문장으로 다시 번역합니다. 바뀐 낱말이 있으면 "용어집에 넣을까요?"라고 묻고, 넣으면 번역에는 바로, 음성 인식에는 다음 시작부터 반영됩니다. 저장된 회의도 회의 정리 화면의 전체 기록에서 ✎로 영어와 한국어를 고칠 수 있습니다.
- **지난 회의 대비 변경점**: 같은 묶음에 정리가 있는 앞 회의가 있으면, 회의 정리에 "지난 회의 대비 변경점"이 생깁니다 (예: "납기: 6주 → 8주"). 아래에 비교한 회의 이름이 나오고, "원문" 단추로 그 말이 나온 줄로 갈 수 있습니다.

## 기타 설정
- **답변 제안·회의 정리에 쓸 AI**: 번역 엔진과 따로 고를 수 있습니다. 예) 번역은 Groq, 회의 정리는 Claude Sonnet.
- **키 기억하기**: 끄면 API 키를 브라우저 창을 닫을 때 지웁니다. "키 모두 지우기"로 바로 지울 수도 있습니다.
- **버전**: 설정 창 왼쪽 아래에 버전이 보입니다. 새 버전이 올라오면 회의 중이 아닐 때 새로고침하라고 알려 줍니다.
- **정리 갱신**: 줄 수가 같아도 기록 내용이 바뀌면 정리를 새로 만듭니다.
- **되살리기**: 첫 화면의 "백업 파일에서 되살리기"로 백업 파일을 바로 고를 수 있습니다.

## 회의 정리와 답변 제안 (Claude 또는 Groq 키가 있을 때)
- **회의 정리**: 정지하면 회의 내용을 보고 제목, 요약, 결정 사항, 할 일을 만듭니다. 위쪽 "회의 정리" 버튼이나 지난 회의의 "열기"로 봅니다. 회의 중에 눌러도 그때까지의 내용을 정리합니다.
- **묶음에 쌓기**: 정리에서 뽑힌 새 용어, 기억해 둘 내용, 받은 질문 가운데 맞는 것만 골라 묶음에 추가합니다. 추가한 내용은 설정의 회의 묶음에서 고칠 수 있고, 다음 회의의 번역과 답변 제안에 쓰입니다.
- **답변 제안**: 물음표로 끝나는 말이 들리면 영어로 할 수 있는 답변 두 가지를 화면 아래에 제안합니다. 제안을 누르면 영어 문장이 복사됩니다. "지금 제안"은 질문이 아니어도 방금 들린 말에 대해 제안합니다.
- **한국어를 영어로**: 답변 제안 칸 아래에 한국어로 적고 Enter를 누르면 회의에서 쓸 영어 표현으로 바꿔 줍니다.
- **내 정보, 쌓인 내용, 자주 받는 질문과 내 답변**: 설정에 적어 두면 답변 제안이 이 내용을 바탕으로 만들어집니다.
- **백업 알림**: 백업한 뒤 회의가 5건 쌓이면 하루에 한 번 알려 줍니다.

## 번역 품질과 속도 설정 (번역 방식이 Claude 또는 Groq일 때)
- **Groq**: 응답이 빠른 번역 엔진입니다. 번역 방식을 Groq으로 두면 전부 Groq이 번역하고, Claude로 두고 Groq 키만 넣으면 말하는 도중의 미리 번역만 Groq이 맡습니다.
- **회의 배경**: 회의 주제, 참석자, 쟁점을 적어 두면 상황에 맞게 번역합니다.
- **용어집**: 한 줄에 하나씩 적습니다. `escrow = 에스크로`처럼 적으면 항상 그 표현으로 번역하고, 영어만 적으면 그대로 둡니다.
- **안정 모드**: 한 줄의 번역이 Soniox 번역에서 확정 번역으로 한 번만 바뀝니다. 미리 번역과 긴 문장 다듬기를 쓰지 않습니다.
- **긴 문장 다듬기**: 긴 문장을 쉼표에서 끊어 먼저 번역하고, 문장이 끝나면 전체를 다시 번역해 한 줄로 고칩니다.
- **번역 비교 모드**: Soniox 번역과 다른 AI 엔진의 번역을 작은 글씨로 함께 보여 줍니다. 이름 옆 숫자는 문장이 끝난 뒤 그 엔진의 번역이 완성될 때까지 걸린 시간입니다. 품질과 속도를 비교할 때만 켭니다.
- **번역 속도 기록**: 화면 위쪽의 "미리 ○초 · 확정 ○초"를 누르면 Soniox, Claude, Groq의 속도를 같은 기준으로 잰 값(평균, 보통, 느릴 때)을 볼 수 있습니다.
