사용 방법

  1. 설정에서 Soniox API 키를 입력합니다. (처음 한 번)
  2. 시작을 누릅니다.
  3. 화면 공유 창이 뜨면 전체 화면을 고르고 시스템 오디오도 공유를 켠 뒤 공유를 누릅니다.
  4. 회의나 영상에서 영어가 들리면 영어 자막과 한국어 번역이 표시됩니다.

정지를 누르면 요금이 더 이상 발생하지 않습니다. 화면은 녹화되거나 전송되지 않고 소리만 사용합니다.

회의 주제, 참석자, 쟁점을 적어 두면 뜻이 여러 개인 단어를 상황에 맞게 번역합니다.
등록한 단어는 더 정확하게 받아 적습니다. 영어 = 한국어로 적으면 번역할 때 항상 그 표현을 씁니다. 회사명이나 사람 이름처럼 그대로 둘 단어는 영어만 적어 주세요.
답변 제안에 쓰입니다. 회의가 끝난 뒤 '회의 정리'에서 고른 항목이 여기에 추가되고, 직접 고칠 수도 있습니다.
비슷한 질문이 나오면 이 답변을 바탕으로 영어 답변을 제안합니다. 답은 한국어로 적어도 됩니다.
회의 중에는 30초마다, 그리고 정지할 때 영어 원문과 번역이 이 브라우저에 저장됩니다. 소리는 저장하지 않습니다. 남기면 안 되는 회의는 꺼 주세요.
회의 내용 전체를 AI(Claude 또는 Groq)에 한 번 보내 제목, 요약, 결정 사항, 할 일, 새 용어, 받은 질문을 뽑습니다. 꺼 두면 '열기'나 '회의 정리'를 누를 때만 만듭니다. 번역 방식이 Soniox 내장이어도 저장해 둔 키가 있으면 그 키를 씁니다.
'열기'를 누르면 요약과 전체 기록을 보고, 제목을 고치거나 파일로 내려받을 수 있습니다.
묶음과 회의 기록은 이 브라우저에만 저장됩니다. 브라우저 기록을 지우거나 다른 컴퓨터를 쓰면 보이지 않으니, 가끔 내보내기로 파일에 보관해 주세요. API 키는 백업 파일에 들어가지 않습니다.
이 브라우저 창에서는 묶음과 회의 기록을 저장할 수 없습니다 (시크릿 창이거나 저장소가 막혀 있음). 회의 배경과 용어집은 그대로 쓸 수 있습니다.
키는 이 브라우저에만 저장됩니다. 다른 사람과 공유하는 PC에서는 사용 후 지워 주세요.
끄면 키를 이 창에만 두었다가, 브라우저 창을 닫으면 지웁니다. 다음에 열 때 키를 다시 넣어야 합니다. 여러 사람이 쓰는 PC라면 꺼 두세요.

한 줄의 번역이 Soniox 번역에서 확정 번역으로 한 번만 바뀝니다. 말하는 도중의 미리 번역과 긴 문장 다듬기를 쓰지 않아서 화면이 차분해지고 AI 호출도 줄어듭니다. 대신 AI 번역은 문장이 끝난 뒤에 뜹니다.

      

      

        
        
번역 방식이 Claude일 때, 말하는 도중의 미리 번역만 Groq이 맡습니다. 문장이 끝나면 Claude가 확정 번역으로 바꿉니다.

      

      

        
        
말하는 순간 Soniox의 빠른 번역을 흐리게 먼저 보여 주고, AI 번역이 도착하면 바꿉니다.

      

      

        
        
문장이 끝나기 전에 흐린 글씨로 먼저 번역을 보여 주고, 문장이 끝나면 확정 번역으로 바꿉니다. AI 호출 횟수가 늘어납니다.

      

      

        
        
긴 문장을 쉼표에서 끊어 번역을 빨리 보여 주고, 문장이 끝나면 전체를 다시 번역해 한 줄로 자연스럽게 고칩니다. 긴 문장마다 AI 호출이 한 번 늘어납니다.

      

      

        
        
같은 문장을 Soniox와 다른 AI 엔진이 번역한 결과를 작은 글씨로 함께 보여 줍니다. 큰 글씨가 위에서 고른 번역 방식입니다. 이름 옆 숫자는 문장이 끝난 뒤 그 엔진의 번역이 완성될 때까지 걸린 시간입니다. Claude와 Groq 키가 둘 다 있으면 서로를 비교하고, 하나만 있으면 같은 회사의 다른 모델과 비교합니다. 품질을 비교할 때만 켜 주세요.
