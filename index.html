회의 통역 도우미 대기 00:00

사용 방법

  1. 설정에서 Soniox API 키를 입력합니다. (처음 한 번)
  2. 시작을 누릅니다.
  3. 화면 공유 창이 뜨면 전체 화면을 고르고 시스템 오디오도 공유를 켠 뒤 공유를 누릅니다.
  4. 회의나 영상에서 영어가 들리면 영어 자막과 한국어 번역이 표시됩니다.

정지를 누르면 요금이 더 이상 발생하지 않습니다. 화면은 녹화되거나 전송되지 않고 소리만 사용합니다.

설정
키는 이 브라우저에만 저장됩니다. 다른 사람과 공유하는 PC에서는 사용 후 지워 주세요.
아직 연결한 적이 없습니다.
Claude는 한 문장이 끝나는 즉시 번역합니다. 영어 자막은 어느 쪽이든 실시간으로 나옵니다.
키는 이 브라우저에만 저장되고 Claude API로 직접 전송됩니다.
말하는 순간 Soniox의 빠른 번역을 흐리게 먼저 보여 주고, Claude 번역이 도착하면 바꿉니다.
문장이 끝나기 전에 흐린 글씨로 먼저 번역을 보여 주고, 문장이 끝나면 확정 번역으로 바꿉니다. Claude 호출 횟수가 늘어납니다.
등록한 단어는 더 정확하게 받아 적습니다.
말하는 사람이 바뀌면 화자 1, 화자 2처럼 표시합니다. 화자 이름을 누르면 이름을 바꿀 수 있습니다.
