회의 통역 도우미 대기 00:00

사용 방법

  1. 설정에서 Soniox API 키를 입력합니다. (처음 한 번)
  2. 시작을 누릅니다.
  3. 화면 공유 창이 뜨면 전체 화면을 고르고 시스템 오디오도 공유를 켠 뒤 공유를 누릅니다.
  4. 회의나 영상에서 영어가 들리면 영어 자막과 한국어 번역이 표시됩니다.

정지를 누르면 요금이 더 이상 발생하지 않습니다. 화면은 녹화되거나 전송되지 않고 소리만 사용합니다.

설정
키는 이 브라우저에만 저장됩니다. 다른 사람과 공유하는 PC에서는 사용 후 지워 주세요.
아직 연결한 적이 없습니다.
Claude와 Groq은 한 문장이 끝나는 즉시 번역합니다. 영어 자막은 어느 쪽이든 실시간으로 나옵니다. 번역 품질은 아래 비교 모드로 직접 견줘 볼 수 있습니다.
키는 이 브라우저에만 저장되고 Claude API로 직접 전송됩니다. 번역 방식이 Groq이면 비워 둬도 됩니다.
응답이 빠른 번역 엔진입니다. 키는 이 브라우저에만 저장되고 Groq API로 직접 전송됩니다. 키를 넣으면 회의 내용의 글자가 Groq으로도 전송됩니다.
번역 방식이 Claude일 때, 말하는 도중의 미리 번역만 Groq이 맡습니다. 문장이 끝나면 Claude가 확정 번역으로 바꿉니다.
말하는 순간 Soniox의 빠른 번역을 흐리게 먼저 보여 주고, AI 번역이 도착하면 바꿉니다.
문장이 끝나기 전에 흐린 글씨로 먼저 번역을 보여 주고, 문장이 끝나면 확정 번역으로 바꿉니다. AI 호출 횟수가 늘어납니다.
긴 문장을 쉼표에서 끊어 번역을 빨리 보여 주고, 문장이 끝나면 전체를 다시 번역해 한 줄로 자연스럽게 고칩니다. 긴 문장마다 AI 호출이 한 번 늘어납니다.
같은 문장을 Soniox와 다른 AI 엔진이 번역한 결과를 작은 글씨로 함께 보여 줍니다. 큰 글씨가 위에서 고른 번역 방식입니다. 이름 옆 숫자는 문장이 끝난 뒤 그 엔진의 번역이 완성될 때까지 걸린 시간입니다. Claude와 Groq 키가 둘 다 있으면 서로를 비교하고, 하나만 있으면 같은 회사의 다른 모델과 비교합니다. 품질을 비교할 때만 켜 주세요. AI 호출이 약 두 배로 늘어납니다.
회의 주제, 참석자, 쟁점을 적어 두면 뜻이 여러 개인 단어를 상황에 맞게 번역합니다. 회의마다 바꿔 주세요.
등록한 단어는 더 정확하게 받아 적습니다. 영어 = 한국어로 적으면 번역할 때 항상 그 표현을 씁니다. 회사명이나 사람 이름처럼 그대로 둘 단어는 영어만 적어 주세요.
말하는 사람이 바뀌면 화자 1, 화자 2처럼 표시합니다. 화자 이름을 누르면 이름을 바꿀 수 있습니다.

      
엔진별 속도는 Soniox, Claude, Groq을 같은 기준으로 잰 값입니다. 영어 문장이 확정된 순간부터 그 엔진의 번역이 완성될 때까지 걸린 시간입니다. Soniox는 즉시 번역이나 비교 모드가 켜져 있을 때, 두 번째 AI 엔진은 비교 모드가 켜져 있을 때 기록됩니다. 보통은 중간값, 느릴 때는 가장 느린 10% 구간의 값입니다. 시작을 누를 때마다 새로 쌓입니다.
